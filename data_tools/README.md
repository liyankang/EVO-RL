# 机器人数据集处理平台

基于 Streamlit 的机器人数据集（LeRobot 格式）处理平台，提供数据加载、轨迹裁剪、动作平滑和数据对齐检查功能。

## 🚀 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动应用

```bash
# 使用启动脚本（推荐）
bash run_streamlit_app.sh

# 或直接使用 streamlit
streamlit run streamlit_app.py
```

应用将在浏览器中自动打开: http://localhost:8501

## 📋 功能介绍

### 📂 数据加载（主页）
- 交互式文件夹浏览器
- 自动识别 LeRobot 格式数据集
- 显示数据集统计信息概览
- Episode 列表和详情展示

### ✂️ 轨迹裁剪
- 基于时间戳或帧数的轨迹裁剪
- 可视化时间轴滑块
- 动作数据预览
- 同步处理轨迹和视频数据
- 自动备份功能

### 🛠️ 动作平滑
- Savitzky-Golay 滤波器
- 高斯滤波
- 平滑效果预览
- 详细的平滑统计信息
- 支持自定义参数

### ✅ 数据对齐检查
- 视频与轨迹数据对齐检查
- 批量检查所有 Episodes
- 详细的对齐报告
- 时间戳一致性分析
- 数据集质量统计

## 💡 使用流程

1. **加载数据集**: 在 "📂 数据加载" 页面选择并加载数据集
2. **数据处理**: 根据需要选择相应的功能页面
   - 使用 "✂️ 轨迹裁剪" 去除不需要的数据段
   - 使用 "🛠️ 动作平滑" 减少动作数据的噪声
   - 使用 "✅ 数据对齐检查" 确保数据质量
3. **数据验证**: 定期使用数据对齐检查功能验证数据质量

## ⚙️ 配置说明

### 数据集格式要求
LeRobot 格式数据集应包含以下结构：
```
dataset_name/
├── data/
│   └── chunk-000/
│       ├── episode_000000.parquet
│       └── ...
├── meta/
│   ├── info.json
│   ├── episodes.jsonl
│   └── ...
└── videos/
    └── chunk-000/
        ├── observation.images.primary/
        │   └── episode_000000.mp4
        └── ...
```

### 环境变量
- `PYTHONPATH`: 添加 data_tools 目录到 Python 路径

## ⚠️ 注意事项

1. **数据备份**: 执行裁剪和平滑操作前，请确保有数据备份
2. **性能考虑**: 处理大型数据集可能需要较长时间
3. **磁盘空间**: 视频处理需要足够的临时磁盘空间
4. **浏览器兼容**: 建议使用现代浏览器（Chrome, Firefox, Safari）
5. **Python 版本**: 建议使用 Python 3.8+

## 🐛 故障排除

### 应用无法启动
```bash
# 检查依赖是否完整
pip install -r requirements.txt

# 检查 Python 版本
python3 --version
```

### 数据加载失败
- 确认数据集格式符合 LeRobot 标准
- 检查文件权限
- 验证 info.json 文件完整性

### 视频处理失败
- 安装视频编解码器
- 检查磁盘空间
- 验证视频文件完整性

## 📊 性能优化

- 使用 SSD 存储数据集
- 增加系统内存
- 关闭不必要的浏览器标签
- 使用本地运行而非远程服务器
